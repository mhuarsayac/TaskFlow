# TaskFlow

### Aplicación web para la gestión de tareas en equipo

## Descripción
TaskFlow es una aplicación sencilla que permite a los equipos organizar, administrar y realizar un seguimiento de sus tareas, facilitando la colaboración y la distribución del trabajo.

## Funcionalidades
- Registrar nuevas tareas.
- Editar tareas existentes.
- Eliminar tareas.
- Asignas tareas a los usuarios.
- Consultar las tareas registradas.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Git y GitHub

## Requisitos
Para utilizar y ejecutar el proyecto se necesita:

- Un navegador web actualizado.
- Git instalado para clonar el repositorio.
- Un editor de código, como Visual Studio Code.
